# 安德鲁牙科连锁管理系统

系统分析与设计课程项目。实现使用「和安口腔」作为演示品牌。

## 课程验收入口

### 网页管理后台

| 项目 | 访问方式 |
| --- | --- |
| 登录入口 | [和安口腔管理后台](https://dental.know11know.top/) |
| 管理员账号 | `dental_admin` |
| 管理员密码 | 由项目作者单独提供给课程老师 |
| 服务端 API | [门店目录接口示例](https://api.know11know.top/api/v1/catalog/clinics) |

登录后可查看工作台、排班、预约、接诊与治疗、结算、复诊和经营统计。办理流程时请使用虚构演示资料。

### 微信小程序「牙牙课程演示」

课程展示使用微信体验版。请联系项目作者，将老师实际使用的微信号加入体验成员，再用该账号扫描项目作者提供的体验二维码。交接记录中的新版为开发版 0.2.8，体验版本以微信后台实际配置为准。

等待开通体验权限时，可以先查看[小程序首页](demo/miniprogram-home.png)、[门店选择](demo/miniprogram-clinics.png)和[预约确认](demo/miniprogram-booking.png)截图。
